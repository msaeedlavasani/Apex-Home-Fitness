# مشخصات فنی پروژه (Technical Spec)

## هدف
ایجاد یک پلتفرم هوشمند برای تولید و اجرای برنامه‌های ورزشی خانگی (Home Workout) متناسب با تجهیزات موجود، محدودیت‌ها و اهداف کاربر.

## معماری سیستم
1. **لایه هوش مصنوعی:** Vercel AI SDK (GPT-4o-mini) وظیفه ترکیب متدهای ورزشی (Yoga, HIIT, Calisthenics, Pilates, etc.) را دارد.
2. **لایه فیلترینگ:** فیلترینگ سخت‌افزاری و جسمی قبل از ارسال به AI انجام می‌شود.
3. **Design System:** سیستم طراحی چندپلتفرمی (iOS, Android, Web) با تم‌های Light/Dark.
4. **Workout Engine:** مدیریت ماشین وضعیت تمرین به صورت زنده.
5. **Offline Layer:** استفاده از IndexedDB برای ردیابی تمرینات بدون اینترنت.

## مدل داده (Prisma)
- **User:** پروفایل و تنظیمات.
- **Exercise:** دیتابیس ۴۰+ حرکت ورزشی پایه.
- **Program:** برنامه‌های تولید شده توسط AI.
- **WorkoutSession:** تاریخچه جلسات تمرینی.
- **QuizResponse:** پاسخ‌های کوییز ورودی.
